04

Deploy atau update API

bash /var/www/sambal-joelid/ops/deploy-vps.sh
systemctl status sambal-joelid-api --no-pager
curl -fsS https://api.joelid.hontalk.my.id/api/v1/health
Expected: script membuat backup, menjalankan git pull --ff-only, memasang dependency, memverifikasi binding native better-sqlite3, menjalankan test, lalu restart hanya jika seluruh tahap berhasil. Health mengembalikan {"ok":true}.
Ownership: deployment dijalankan sebagai root, tetapi Git dan npm dijalankan sebagai user sambal. Script memperbaiki ownership node_modules yang mungkin pernah dibuat oleh root agar npm ci tidak gagal dengan EACCES.
Native install security: package.json hanya mengizinkan install script untuk versi terpin better-sqlite3 dan esbuild. Jika native build tetap gagal, pasang toolchain sekali dengan apt-get install -y build-essential python3, lalu jalankan kembali script deployment. Jangan menghapus package-lock.json di VPS.

06

Vercel

  • Repository terhubung ke branch main.
  • Build mengikuti vercel.json dan hanya workspace web.
  • VITE_API_BASE_URL=https://api.joelid.hontalk.my.id/api/v1.
  • Custom domain customer dan admin harus ditambahkan ke project Vercel, bukan hanya dibuat sebagai DNS record.
  • Jika nameserver domain dikelola Cloudflare, record dibuat di Cloudflare. Host admin bertingkat menggunakan mode DNS only agar sertifikat Vercel dapat diterbitkan.
  • Header x-vercel-cache dapat dipakai untuk memastikan origin Vercel.
