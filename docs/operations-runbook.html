Normal: API {"ok":true}, WAHA healthy dan session WORKING, Qwen menampilkan alias model. Halaman Ikhtisar admin juga menampilkan kesehatan integrasi WhatsApp.

Membuka Dashboard WAHA dari Komputer Lokal:

Karena port 3000 hanya dibuka di loopback VPS (127.0.0.1:3000), buka terminal komputer lokal Anda dan jalankan SSH Tunnel:

# Dari terminal laptop / PC lokal Anda:
ssh -p <SSH_PORT> -N -L 3000:127.0.0.1:3000 sambal@<VPS_HOST>

# Buka browser lokal:
# http://localhost:3000/dashboard atau http://localhost:3000/api/docs

02

Backup

bash /var/www/sambal-joelid/ops/backup-sqlite.sh
ls -lh /var/backups/sambal-joelid
systemctl list-timers | grep sambal

SQLite memakai .backup agar aman dalam mode WAL. Hasil dikompresi ke /var/backups/sambal-joelid/customer-module-TANGGAL-JAM.sqlite.gz. Setiap eksekusi juga menghapus backup database yang berumur lebih dari 14 hari. Backup konfigurasi ditempatkan di /var/backups/sambal-joelid/config, bukan di repository. Session WAHA berada di /var/lib/waha.

Backup lokal bukan disaster recovery. Salin backup terenkripsi ke storage berbeda dan uji restore berkala.

03

Restart aman

API
systemctl restart sambal-joelid-api
journalctl -u sambal-joelid-api -n 50 --no-pager
WAHA
cd /opt/waha
docker compose restart waha
sleep 20
docker compose ps

Setelah restart WAHA, session harus kembali WORKING tanpa QR. Jangan menghapus /var/lib/waha.

04

Acceptance test

  1. General: kirim sapaan dan pastikan petunjuk keyword ditampilkan.
  2. Menu: kirim menu; pastikan hanya item CSV yang aktif dan memiliki stok yang ditampilkan.
  3. Order: kirim kalimat informal, item, jumlah, dan cabang; verifikasi total backend; balas YA.
  4. Complaint: kirim keluhan lengkap; verifikasi ringkasan; balas YA.
  5. Handoff: kirim “admin”; pastikan WAITING_ADMIN. Balasan dashboard mengubahnya menjadi ADMIN_ACTIVE, lalu kembali otomatis ke AI_ACTIVE.
  6. Dashboard: ubah status order/keluhan, buka bubble chat, dan pastikan data WhatsApp memiliki tombol percakapan.
  7. Outage: matikan tunnel Qwen sementara; pastikan fallback operasional dikirim.
  8. Persistence: restart WAHA; pastikan session kembali WORKING.

06

Aturan keamanan

  • Jangan menaruh secret, QR, pairing code, nomor pelanggan, atau payload webhook di issue/chat.
  • WAHA hanya loopback; akses dashboard melalui SSH port forwarding.
  • Gunakan secret berbeda untuk JWT, WAHA API, webhook HMAC, AI API, dan tunnel.
  • Log WAHA production berada pada level warn.
  • Jangan menjalankan git reset --hard pada VPS saat ada perubahan lokal.
  • Rotasi segera credential yang pernah terlihat pada terminal publik atau percakapan.

Retensi dan beban penyimpanan

  • Pesan WhatsApp disimpan di SQLite sesuai WHATSAPP_MESSAGE_RETENTION_DAYS (default 30 hari) dan dibersihkan saat API startup.
  • Pending action yang telah selesai mengikuti retensi yang sama; order, keluhan, dan record percakapan tidak memiliki penghapusan otomatis.
  • Data utama berada pada disk VPS di file SQLite. RAM hanya digunakan sementara untuk query aktif, cache katalog, rate-limit bucket, dan antrean AI.
  • Backup SQLite terkompresi disimpan 14 hari oleh script backup. Untuk disaster recovery, salin backup terenkripsi ke storage terpisah.
