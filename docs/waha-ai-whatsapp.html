03

Qwen di Termux

./build/bin/llama-server \
  --model "$HOME/models/Qwen2.5-1.5B-Instruct-Q4_K_M.gguf" \
  --alias qwen2.5-1.5b-instruct \
  --host 127.0.0.1 --port 8080 \
  --ctx-size 2048 --parallel 1 --threads 4 \
  --n-predict 300 --api-key '<AI_API_KEY>' --no-ui
  • termux-wake-lock aktif.
  • Battery optimization Termux dinonaktifkan.
  • cloudflared tunnel run --token <token> berjalan terpisah.
  • Hostname statis: qwen.hontalk.my.id.
  • Backend timeout 90 detik dan concurrency satu.
Tiga secret berbeda: tunnel token menghubungkan cloudflared; AI API key melindungi llama-server; WAHA API key melindungi API WAHA. Jangan saling menggunakan ulang.

04

Webhook aman

WAHA mengirim ke endpoint HTTPS karena firewall VPS mengisolasi bridge Docker dari port aplikasi.

POST https://api.joelid.hontalk.my.id/api/v1/integrations/waha/webhook

X-Webhook-Hmac: <sha512 raw body>
X-Webhook-Hmac-Algorithm: sha512
  • Raw body diverifikasi dengan timing-safe comparison.
  • Session wajib sambal-joelid.
  • Grup, channel, status, media, dan pesan fromMe diabaikan.
  • Message ID unik mencegah transaksi ganda.
  • Chat ID GOWS @lid disimpan untuk balasan; nomor alternatif dipakai sebagai data customer.

05

AI bukan sumber kebenaran

IntentPerilaku backend
GENERAL_QUESTIONQwen menjawab dengan konteks menu dan cabang aktif.
ORDERBackend memvalidasi menu/cabang, menghitung harga, meminta YA/BATAL, lalu commit.
COMPLAINTPesan asli menjadi fallback deskripsi; selalu meminta YA/BATAL sebelum commit.
HANDOFFState menjadi WAITING_ADMIN; AI berhenti.

Output Qwen dibatasi JSON Schema. Jika model kecil tetap menghasilkan output tidak lengkap, backend memakai safe response sebagai lapisan darurat—bukan respons normal.
